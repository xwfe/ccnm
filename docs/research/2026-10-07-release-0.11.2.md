# 发版 v0.11.2，三台换装（2026-10-07）

P73 做完后，用户要求"推送，发 v0.11.2 并换装三台"。做法与 [v0.11.1](2026-10-07-release-0.11.1.md) 相同，这里只记不同的数字。

## 1. 版本号

**0.11.2，补丁号。** 只改 doctor 的结论判断（[P73 记录](2026-10-07-p73-doctor-note-rows.md)）：设计上不查的行记"不查"（NOTE），不再挡结论，配置正常时最后一行是"可以用了"、退出 0。**用 doctor 退出码做判断的脚本要知道**：同一份正常配置，v0.11.1 退出 3，这一版退出 0（仓库里唯一的使用方 `scripts/deploy.sh` 只判 10，不受影响）。内部协议号没变（仍是 10），几台要一起升。

## 3. 三台换装

都用"新文件 + 改名"。

| | 本机（Runtime / Operator） | fodelf（Agent） | hpsrv `ccrun` |
| --- | --- | --- | --- |
| 换之前 | v0.11.1 `fb0a27c8…` | 同左，Controller pid 21418 | v0.11.1 `d8422cbf…` |
| 回退目标 | `~/.local/opt/ccnm-0.11.1/ccnm` | 同一路径，另有 Controller 的 plist | `~/.local/opt/ccnm-0.11.1/ccnm` |
| 之后 | `ccnm 0.11.2`，`67ebe312…` | 同左；`controller install` 后 pid 62225，`ccnm 0.11.2 as fodelf … Aqua`，plist 与备份逐字相同 | `ccnm 0.11.2`，`713909c5…`，副本在 `~/.local/opt/ccnm-0.11.2/` |

**核对**：四个日用 workspace（`ccnm`、`xdo`、`xshun`、`gld`）的 `ccnm doctor` 都是 **"可以用了（3 项不查，原因写在标"不查"的行里）"、退出 0**，0 项失败、0 项没查——换装前（v0.11.1）同一份配置是"还不能用（0 项失败，3 项没查）"、退出 3。零额度冒烟：`ccnm run ccnm --detached` 由新 Controller 起会话，Claude Code 停在输入框，本机起了 `mcp-serve`；不发消息，`ccnm stop ccnm --session 256a2593…` 退出 0，`mcp-serve` 退出，`ccnm log` 记"被停止"，四个写锁标记都是 `released`，fodelf 上没有 tmux 残留。hpsrv 只核了版本号与 sha256。没有调用模型。

**回退**（本机与 fodelf 要一起退）：

```bash
install -m 755 ~/.local/opt/ccnm-0.11.1/ccnm ~/.local/bin/ccnm.new && mv ~/.local/bin/ccnm.new ~/.local/bin/ccnm
```

fodelf 上同一条，再跑 `~/.local/bin/ccnm controller install`。hpsrv 以 ccrun 跑同一条。
