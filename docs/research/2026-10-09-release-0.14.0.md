# 发版 v0.14.0，三台换装（2026-10-09）

用户 2026-10-09 在 P85 之后说"推送发版，并三机安装"。做法与 [v0.13.1](2026-10-08-release-0.13.1.md) 相同，这里只记不同的地方和结果。

## 1. 版本号

**0.14.0，次版本号**：P86 删了配置键 `codex_exec_server`，写着它的配置（哪怕是 `false`）解析失败，这是不兼容改动。P84、P85 只加不改。内部协议号没变（仍是 10），几台仍要一起升，两端版本号不同时 doctor 和起会话报 `CCNM_E_VERSION`。换装前核对过，三台的日用配置都没写这个键。

| 带了什么 | 记录 |
| --- | --- |
| P86 删掉封存的 Codex 原生执行链（`native/`、`internal exec-transport`/`exec-serve`、doctor 那一行，代码 +107/-6089） | `docs/plan/ROADMAP.md` P86、[双执行入口方案](../plan/runtime-surfaces.md)第 12 节 |
| P84 Linux 上 `mcp-serve` 是后代的 subreaper，会话结束时收掉 `setsid` 出去的后代再交写锁；macOS 不变（用户定不做） | [P84](2026-10-09-p84-linux-orphans.md) |
