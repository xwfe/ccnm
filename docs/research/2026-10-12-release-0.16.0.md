# 发版 v0.16.0，三台换装（2026-10-12）

用户 2026-10-12 在 P88 之后说"推送发版，三机安装"。做法与 [v0.15.0](2026-10-11-release-0.15.0.md) 相同，这里只记不同的地方和结果。

## 1. 版本号

**0.16.0，次版本号**：P88 改了受管 Claude 会话的默认行为（压缩窗口 30 万改 56 万，压缩指令重写），配置没有不兼容的地方。内部协议号没变（仍是 10），几台仍要一起升，两端版本号不同时 doctor 和起会话报 `CCNM_E_VERSION`。

| 带了什么 | 记录 |
| --- | --- |
| P88 受管 Claude 会话的 settings.json 里 `autoCompactWindow` 改为 560000，`PreCompact` 钩子交的压缩指令按 Claude Code 自带总结提示重写 | [P88](2026-10-12-p88-compact-560k.md)、[配置说明](../configuration.md#受管-claude-会话的自动压缩) |

v0.15.0 时查出的 tmux 3.7c 下 `ccnm ls`、`ccnm status` 看不见交互会话，这一版没修。
