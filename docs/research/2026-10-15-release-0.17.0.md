# 发版 v0.17.0，三台换装（2026-10-15）

用户 2026-10-15 在 P93 查清原因后同意"把 rmcp 升到 3.5.1，连同 P90–P92 一起发版、三台换装"。做法与 [v0.16.1](2026-10-12-release-0.16.1.md) 相同，这里只记不同的地方和结果。

## 1. 版本号

**0.17.0，次版本号**：加了两个命令行参数（`ws add --allow-unattended-exec`、`ccnm <项目> --continue`），起会话的行为也变了（项目机器不肯开就直接报错）。内部协议号没变（仍是 10），几台仍要一起升，两端版本号不同时 doctor 和起会话报 `CCNM_E_VERSION`。配置不用改。

| 带了什么 | 记录 |
| --- | --- |
| P90 `ccnm ws add --allow-unattended-exec` | `docs/plan/ROADMAP.md` P90、[配置说明](../configuration.md) |
| P91 起会话前问项目机器开不开、命令让不让跑，不行就报 `CCNM_E_POLICY` 不起；每个新会话多一次 SSH（实测 525–806 毫秒） | ROADMAP P91、[排错手册](../troubleshooting.md#ccnm-项目-起不来报-its-runtime-would-refuse-it) |
| P92 `ccnm <项目> -c` 接着这个项目上一次的对话开（只支持 Claude） | ROADMAP P92、[研究记录](2026-10-15-p92-resume.md)、[使用说明](../usage.md#接着上一次的对话开--continue) |
| P93 rmcp 3.2.0 → 3.5.1：Claude Code 探测新协议、ccnm 起得慢时退回旧协议，会话里不再一个工具都没有 | ROADMAP P93、[研究记录](2026-10-15-p93-discover-fallback.md) |
