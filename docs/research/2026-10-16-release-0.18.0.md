# 发版 v0.18.0，三台换装（2026-10-16）

用户 2026-10-16 在 P99 之后说"发个 0.17.1"，又说"几台机器都换上新版"。做法与 [v0.17.0](2026-10-15-release-0.17.0.md) 相同，这里只记不同的地方和结果。

## 1. 版本号

**0.18.0，次版本号**：用户说的是 0.17.1，按 0.17.0 那次的规则（加了命令或参数就升次版本号，补丁号只留给纯修 bug），这批加了 `ccnm add`、`ccnm rm` 两个新命令，问过用户后改发 0.18.0。内部协议号没变（`WIRE_LEVEL` 仍是 10，其他协议常量也都没动），几台仍要一起升，两端版本号不同时 doctor 和起会话报 `CCNM_E_VERSION`。配置不用改。

给人看的输出（起会话的提示、`ls`、`status`、`stop`、`result`、常见报错、`doctor` 结论）改了不少，拿它们写过脚本的要改；`ccnm rpc`、MCP 文本、错误码名、协议字段没动。

| 带了什么 | 记录 |
| --- | --- |
| P94 起会话的提示说人话：开关提醒每个两行加文档链接，会话摘要一行，连不上 Agent 时说下一步 | `docs/plan/ROADMAP.md` P94 |
| P95 `status`、`ls`、`stop`、`result` 和常见报错说人话；doctor 还不能用时点名先看哪行 | ROADMAP P95、[排错手册](../troubleshooting.md#doctor-的表怎么读) |
| P96 Codex 会话工具断了时，提示 `ccnm stop <项目>` 再开新会话，不再指向裸 `codex resume` | ROADMAP P96、[排错手册](../troubleshooting.md#tools-down--会话看着在跑模型却什么都够不着) |
| P97 `ccnm add <项目目录>`，名字取目录名；`ccnm add` 就是 `ccnm ws add` | ROADMAP P97、[配置说明](../configuration.md#cli-改配置) |
| P99 `ccnm rm <名字>`（全称 `remove`）就是 `ccnm ws rm`；`ccnm ls` 和 `ccnm ws ls` 的帮助互相指路 | ROADMAP P99、[使用说明](../usage.md#简写) |

P98（断网后自动重连）排过又撤了，没有代码，见 ROADMAP 末尾。
