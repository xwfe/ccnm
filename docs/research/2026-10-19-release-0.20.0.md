# 发版 v0.20.0，三台换装与 `ccnm usage` 真机复验（2026-10-19）

用户 2026-10-19 在 P105 之后说"发版、三台换装，然后在本机真机跑 ccnm usage 复验"。发版与换装做法同 [v0.19.0](2026-10-17-release-0.19.0.md)，这里只记不同的地方和结果。

## 1. 版本号

**0.20.0，次版本号**：用户没指定版本号。按 0.17.0 起的规则（加命令、加参数升次版本号，补丁号只留给纯修 bug），这次新增了 `ccnm usage`。配置不用改。

几台仍要一起升：新增的内部命令 `internal agent-usage` 和 Controller 的 `usage` 请求只有新版本认得。内部协议号没变（`WIRE_LEVEL` 仍是 10）——旧对端在已有的命令上照常工作，只是不认这两个新东西，`ccnm usage` 碰到时各说一句该怎么办（[排错手册](../troubleshooting.md#ccnm-usage-查不到额度)）。**AI 那台换完文件要重启 Controller**（`ccnm controller install`，和以前每次一样）：不重启，跑着的还是旧进程，`ccnm usage` 报 `the controller here was started by an older ccnm`。
